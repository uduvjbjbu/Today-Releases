# Today — Android 운동 기록 앱

운동 루틴과 실제 수행 기록을 관리하는 **Today**의 공식 APK 배포 저장소입니다.

**최신 버전: Today v0.6.7 (2026-11-27)**

- [v0.6.7 정식 릴리스 및 다운로드](https://github.com/uduvjbjbu/Today-Releases/releases/tag/v0.6.7)
- [v0.6.7 APK 직접 다운로드](https://github.com/uduvjbjbu/Today-Releases/releases/download/v0.6.7/Today-v0.6.7-release.apk)
- [이전 v0.6.6 릴리스](https://github.com/uduvjbjbu/Today-Releases/releases/tag/v0.6.6)

## 새로 추가된 기능

전체 색상 테마 5종, 글자 크기 4단계, 기본/고운돋움/주아체 글꼴 선택 기능. 상단 설정 버튼에서 변경할 수 있습니다.

## 설치 및 업데이트

- **처음 설치**: 최신 APK 파일을 내려받아 설치합니다. Android의 외부 APK 설치 권한이 필요할 수 있습니다.
- **v0.6.6 사용자**: 운동 기록은 미리 JSON으로 백업하는 것을 권장합니다. **기존 Today 앱을 삭제하지 말고** 새 APK로 업데이트하세요. 기존 정식 서명 인증서를 유지합니다.
- `Today TEST`는 별도 앱이므로 정식 버전과 운동 기록이 자동으로 합쳐지지 않습니다.

## 배포 정책

이 저장소는 **서명된 APK 배포 전용**입니다. 소스코드와 개발 이력은 비공개로 유지하며, 정식 서명키와 비밀번호는 공개하지 않습니다.
